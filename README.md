# Harshitha Portfolio

Personal portfolio hub for **Harshitha** (1st-year B.Tech) — Wave 1 foundation.

## Stack

- React + TypeScript + Vite
- Tailwind CSS v4

## Run locally

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```
